# Interactive World Map

## Usage

Note: this project is not ready

This project requires Node.js to run. Install from: `https://nodejs.org/en`

1. Install packages for this project:

```bash
npm install
```

2. Follow the directions in the [scripts folder](/scripts/README.md) to compile the data needed by the project (country and flight information).

3. Run the project in dev mode:

```bash
npm run dev
```

or build for production:

```bash
npm run build
```

and deploy `dist/index.html` as a static site (see [Vite's guide](https://vite.dev/guide/static-deploy)).
